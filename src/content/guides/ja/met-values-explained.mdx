METは代謝当量、つまり安静時代謝率の何倍かを表す値です。1 METは、体が何もしていないときにかかる費用にあたります。8 METの活動は、1分あたりおよそ8倍のエネルギーを使います。

うまい考え方です。体格の違う人どうしでも活動を比べられるようになり、しかも誰かを実際に測る必要がありません。

## 定義

1 METは、**体重1キログラムあたり毎分3.5ミリリットル**の酸素摂取と定義されます。この値は、典型的な成人の安静時代謝を表すものとして選ばれました。

これは約束事であり、やや気前のよい約束事でもあります。実際の集団で測った安静時の酸素摂取は、しばしば2.6〜3.2 mL/kg/分に近く、とくに高齢の人や体重の重い人でそうです。したがって標準のMETは安静時の費用を多めに見積もりがちで、そこから計算した活動のエネルギーも多めになります。

この分野の人は皆それを知っており、それでも約束事が残っているのは、何十年ぶんの公表データを通じた比較可能性のほうが、わずかな正確さの向上より価値があるからです。

## 値の出どころ

Compendium of Physical Activitiesです。Ainsworthらが1993年に初めて公表し、2000年、2011年、そして2024年にAdult Compendiumとして更新されました。

数百の活動にMET値を割り当てており、それぞれに分類と具体的な記述を示す5桁のコードが付いています。値は、エネルギー消費の測定が公表されているものについてはその測定から、ないものについては編者の推定から来ています。この区別はCompendium自身が明記しており、覚えておく価値があります。表のすべての値が実測されたわけではないのです。

いくつか例を挙げます。

| 活動                        | MET  |
| --------------------------- | ---- |
| 静かに座る                  | 1.0  |
| 歩行、時速3 km              | 2.5  |
| 速歩、時速5.5 km            | 4.3  |
| 自転車、時速16〜19 km       | 6.8  |
| ランニング、時速8 km        | 8.3  |
| ランニング、時速11 km       | 11.0 |
| きついウエイトトレーニング  | 6.0  |
| なわとび、中程度            | 11.8 |

## 二つの式、二つの答え

ここが、計算ツールどうしが黙って食い違うところです。自分がどちらを見ているのかを知っておくとよいでしょう。

**簡易式:**

```
kcal = MET × 体重（kg） × 時間
```

1 METが体重1キログラムあたり1時間に約1キロカロリーという近似に基づいています。便利で、実際に近い値です。

**酸素摂取に基づく式:**

```
kcal/分 = MET × 3.5 × 体重（kg） / 200
```

こちらは定義から出発します。1 METは3.5 mL O₂/kg/分。酸素1リットルの消費でおよそ5 kcalが放出される。計算すると、1時間あたり体重1キログラムにつき1.00ではなく1.05 kcalになります。

つまり両者は約**5パーセント**違い、簡易式のほうが低く出ます。どちらが正しいというものではありません。この差は、同じ活動をする二人のあいだのばらつきよりずっと小さいのです。とはいえ一方を表示する計算ツールと他方を表示する計算ツールの答えは一致せず、どちらも理由を説明してはくれません。[消費カロリーの計算ツール](/ja/calculators/calories-burned/)は両方を表示します。

## 総量か、上乗せ分か

より影響の大きい区別であり、多くの計算ツールが触れずに間違えている点です。

METから導いた値は**総**エネルギー消費量です。その1時間に体が使ったすべてであり、どのみち使っていた安静時代謝を含みます。

その運動が何を_上乗せしたか_を知りたいなら、基礎の分を引いてください。

```
上乗せ分の kcal = (MET − 1) × 体重（kg） × 時間
```

体重70 kgの人が8 METで1時間動いた場合、総量は560 kcal、上乗せ分は490 kcalです。差の70 kcalは、その1時間ソファに座っていても燃やしていたぶんです。

これは維持量の上に運動を足すときに効いてきます。維持量にはその時間の安静時代謝がすでに含まれているからです。総量の数字を使えば、それを二重に数えることになります。

## これらはどれほど正確か

小数点以下2桁の出力が思わせるほどではありません。

MET値は集団の平均です。ある活動の実際のエネルギー消費は、体力によって変わります。鍛えた自転車乗りは同じ速度でもより経済的です。体組成、動作の技術、路面、風、さらには休息中にどれだけそわそわするかでも変わります。

Compendium自身、個人のエネルギー消費が表の値からかなり外れうると述べています。MET由来の推定を間接熱量測定と比較した研究では、個人単位で20〜30パーセントの食い違いがよく報告されます。

体格の大きい人については系統的な問題もあります。METの枠組みは体重で標準化しており、エネルギー消費が体重に比例することを前提にします。厳密にはそうではありません。体重の重い人は、線形モデルが示すよりも1キログラムあたりでいくらか経済的な傾向があり、METに基づく推定は高めに出ます。

消費カロリーの数字は桁の目安として扱ってください。「およそ500であって、およそ200でもおよそ1,000でもない」という具合です。

## 二重計上の落とし穴

これらの計算ツールで最も多い実務上の誤りは、はっきり書いておく価値があります。

[1日の消費量](/ja/calculators/tdee/)を、すでにトレーニングを前提とする活動係数——「中程度に活動的、週に3〜5日運動」——で決めているなら、その係数にはあなたの運動が含まれています。その上に消費カロリーの数字を足せば、二重に数えることになります。

どちらかを選んでください。

- **活動係数がトレーニングを含む。** 運動ぶんのカロリーは足さない。最も単純で、たいていの人にはこれが正解です。
- **活動を座位中心にして、各セッションを個別に足す。** 不定期に運動するなら正確ですが、記録の手間は増えます。

両者を混ぜると、目標が数百キロカロリー高くなります。「維持量で食べている」のに体重が増える、というのはまさにこの状況です。

## MET値が本当に役立つ場面

会計ではなく、比較です。

なわとびが速歩の1分あたりおよそ2倍の費用だと教えてくれる数字は信頼できます。あなたのその日のセッションがちょうど437 kcalを燃やしたと告げる数字は信頼できません。

活動を選ぶために、ゆるい自転車1時間が大きな食事を帳消しにしない理由を理解するために、そしてある強度が時間に見合うかを確かめるために使ってください。食べ戻すための帳簿として使わないことです。
