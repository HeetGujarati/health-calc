100 kgを5回挙げました。あなたの1回挙上最大重量はいくつでしょうか。

公表された5つの式がそれに答え、116.7、112.5、117.5、112.5、116.6という値を返します。5キログラムの幅。役に立つ程度には小さく、理解しておく価値がある程度には大きい差です。

## 5つの式

**Epley**（1985年）:

```
1RM = 重量 × (1 + r / 30)
```

**Brzycki**（1993年）:

```
1RM = 重量 × 36 / (37 − r)
```

**Lombardi**（1989年）:

```
1RM = 重量 × r^0.10
```

**O'Conner**（1989年）:

```
1RM = 重量 × (1 + r / 40)
```

**Wathan**（1994年）:

```
1RM = 100 × 重量 / (48.8 + 53.8 × e^(−0.075r))
```

三つの形が含まれています。EpleyとO'Connerは直線型で、1回ごとに一定の割合を足します。Lombardiはべき関数です。Wathanは指数型で、この中で最も精緻なモデルであり、最も広い範囲で素直にふるまいます。

## 一致するところ

低回数では、ぴたりと。1回、2回、3回では5つの式は数パーセント以内に収まります。どれもその領域のデータに当てはめられており、食い違う余地がほとんどないからです。

実務上の要点はこれです。**3回のセットから得た推定は、10回のセットから得た推定よりはるかに価値があります。** 使える1RMの数字がほしいなら、12回で限界まで追い込むより、重い3回を測ってください。

## 割れるところ

およそ10回を超えると、はっきりと。

100 kgで15回の場合、Epleyは150、Brzyckiは163.6、O'Connerは137.5を返します。26 kgの幅で、どの式の実用的な精度よりも広いのです。

理由は数学ではなく生理です。10〜12回のあたりで、制限要因は最大筋力ではなくなり筋持久力に移ります。そして最大値に対する一定割合での持久力は、人によって大きく異なります。最大の70パーセントで20回できる人もいれば、12回で止まる人もいます。重量と回数しか受け取らない式に、あなたがどちらかは分かりません。

5つとも2〜10回の範囲で検証されています。それを超えると外挿になり、土台の形が違うぶん外挿のしかたも違ってきます。

## 幅を読む

[1RMの計算ツール](/ja/calculators/one-rep-max/)を使ううえで最も有用な習慣がこれです。選んだひとつだけでなく、5つの推定がどれだけ離れているかを見てください。

数キログラム以内にまとまっていれば、その推定は信頼できます。10 kg以上に広がっていれば信頼度はずっと低く、正直な読み方は「その帯のどこか」です。

5つの平均は、どれか1つの式よりも根拠のある単一の数字になります。重量と回数の関係の形について、特定のモデルの前提に肩入れしないからです。計算ツールがそれを表示しているのは、この理由からです。

## 知っておく価値のある二つの癖

**Epleyは1回では厳密でありません。** 100 kgの1回を入れると103.3 kgを返します。式が1という係数にr/30を足すだけで、r = 1を特別扱いしないからです。Brzycki、Lombardi、Wathanは挙上重量そのものを返します。これはEpleyの既知の性質であって不具合ではなく、Epleyは3回以上で使うのが良いとされる理由でもあります。

**Brzyckiは37回で定義できなくなります。** 分母が37 − rで、そこでゼロになるからです。計算ツールは無限大ではなく「値なし」を返しますが、そもそも入力の検証が、そこに届くはるか手前で回数に上限をかけています。

## 式より種目のほうが効く

これは誰も触れない限界であり、式どうしの差より大きなものです。

これらの式は主にベンチプレスとスクワットのデータから導かれました。回数と重量の関係は、種目ごとに同じではありません。

**デッドリフト**は、同じ割合の重量に対して式の予測より少ない回数しかこなせないのがふつうで、推定は高めに出ます。握力の疲労、静止状態から引くために伸張反射が使えないこと、全身への負担の大きさが、いずれも影響します。

**オリンピック種目**——クリーンやスナッチ——はそもそもこの方法で推定すべきではありません。制限するのは技術と力の立ち上がりの速さであって、粘って押し切る力ではなく、疲労下での技術の崩れは重量と回数のモデルでは捉えられません。

**単関節種目**は、同じ割合の重量で多関節種目より多く反復できる傾向があるため、推定は低めに出ます。

ベンチプレスやスクワット以外の種目に使うなら、一定の向きに系統的なずれが出ることを見込み、自分自身の測定を重ねて較正してください。

## 本当の最大重量を測るべきか

競技のためなら、はい。補助者と入念なウォームアップ、そして試技の計画を伴って行ってください。

プログラムを組むためなら、たいていは不要です。重い3回からの推定はほぼ同じだけ役に立ち、けがの危険ははるかに小さく、本気の最大挑戦が要求する回復の日数もかかりません。多くの筋力プログラムはそもそも近似の割合の上に成り立っており、想定した最大重量の3パーセントの誤差は、どのみちその日の感覚で調整するという事実に吸収されます。

## 割合の使い方

[割合の表](/ja/calculators/one-rep-max/)は、推定した最大重量をトレーニング重量に変換します。おおまかには次のとおりです。

- **50〜65パーセント** — 技術練習、スピード練習、高回数の補助種目
- **70〜80パーセント** — 筋肥大トレーニングの大半、6〜12回のセット
- **80〜90パーセント** — 筋力トレーニング、3〜6回のセット
- **90パーセント以上** — ピーキング、1回と2回のセット

これらの割合が、すでに誤差を含む推定の上に乗っていることを忘れないでください。指定された85パーセントが95のように感じるなら、推定が高すぎたのです。計算を信じるのではなく、使用重量のほうを調整してください。バーベルは式よりも良いデータです。
