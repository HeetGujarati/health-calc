体格指数は、キログラムで表した体重をメートルで表した身長の2乗で割ったものです。計算はそれだけです。あなたの体重が何でできているか、どこに付いているか、健康状態がどうかについての情報は一切含みません。

これはより良いデータで直る欠点ではありません。この指標とはそういうものなのです。

## もともと個人のためのものではなかった

この比はベルギーの統計学者アドルフ・ケトレーに由来し、彼が活動したのは1830年代です。彼は肥満を研究していたのではなく、自ら平均人と呼んだものの特徴を記述しようとしており、集団を通じて体重を身長で標準化する方法を求めていました。この指数はその役目を果たしました。

現在の名前と用途を得たのは1972年です。アンセル・キーズらが複数の身長対体重の指数を比較し、大標本での実測体脂肪と最もよく相関するのはどれかを調べました。ケトレーの指数は十分に良好な成績を示し、しかも体重計と巻き尺さえあれば済みました。キーズはこれを体格指数と名づけ、個人の診断ではなく集団研究に適していると明言しています。

その区別はそれ以来ずっと薄れ続けてきました。理由の大半は、BMIが安価で、それより優れたものはどれも安価でないことにあります。

## 本当に得意なこと

大きな集団では、BMIは体脂肪量とそれなりによく相関し、体重といくつかの健康上の帰結との関係を追えます。再現性もあります。同じ人を二人が測っても同じ数字になり、これは皮下脂肪厚計には当てはまりません。体重計と壁以外の器具は要りません。

疫学にとって、この組み合わせはなかなか他に代えがたいものです。ある国の肥満率が20年で上がったかを知りたければ、BMIはすでに手元にあるデータから答えを出します。

ふるい分けとしては、最初のフィルターとして機能します。健康的な範囲から大きく外れたBMIは、より詳しく見る妥当なきっかけになります。何が見つかるかまでは教えてくれません。

## 構造上できないこと

**筋肉と脂肪を区別できません。** 筋肉は脂肪より密度が高いので、体格が同じなら筋肉質な人のほうが重くなります。ラグビーのフォワードや競技として重量を挙げる人は、体脂肪がごくわずかでも過体重や肥満の範囲に入るのが普通です。この指数には、それを検出しうる項が存在しません。

**脂肪がどこに付いているかを見られません。** 臓器のまわりの内臓脂肪は、腰や太ももの皮下脂肪よりはるかに大きな代謝リスクを伴います。同じBMIでも脂肪の分布が違う二人は、意味のある差をもつリスク像を示します。ウエスト周囲径やウエスト身長比が支持を広げてきたのはそのためで、米陸軍は2026年、本質的にこの理由から体組成の評価体系すべてをウエスト身長比に置き換えました。

**身長の両極で系統的に読み違えます。** 身長の2乗で割るのは集団データに合った経験的な選択であって、体がどう大きくなるかの記述ではありません。実際の体は、次元によって2乗と3乗のあいだのどこかで大きくなります。その結果、BMIは背の高い人でやや高く、低い人でやや低く出ます。純粋に指数の作りだす人為的な偏りです。身長の3乗で割る[ポンデラル指数](/ja/calculators/bmi/)は、両極でより素直にふるまい、中ほどでは劣ります。

**主にヨーロッパ系の集団から導かれました。** WHO自身が、BMIと健康リスクの関係は集団によって異なると述べており、南アジア系・東アジア系の人にはより低い閾値を用いる国が複数あります。そこでは心血管代謝リスクがより低いBMIで現れるからです。単一の世界共通の区分値が誰にでも正しいということはありえません。

**子どもには当てはまりません。** 成長の過程で体組成は大きく変わるため、成人の区分は18歳未満では意味を持ちません。小児の評価には年齢別・性別のパーセンタイル曲線を用い、臨床的な解釈が必要になります。

## 区分を一度だけ示す

WHOの成人向け区分値は次のとおりです。

| BMI      | 区分         |
| -------- | ------------ |
| 18.5未満 | 低体重       |
| 18.5〜25 | 健康的な体重 |
| 25〜30   | 過体重       |
| 30〜35   | 肥満1度      |
| 35〜40   | 肥満2度      |
| 40以上   | 肥満3度      |

知っておく価値のある技術的な注意点がひとつあります。広く引用される「18.5〜24.9」は丸めた表現です。実際の境界は25.0なので、BMI 24.95は健康的な範囲に入ります。「24.9以下」で判定する計算ツールは、まさにその境目を取り違えています。

これらは集団データから引かれたふるい分けの帯です。生物学的な境界ではなく、BMIが24.9から25.1に変わっても体の中では何も変わりません。

## それでもなぜ至るところにあるのか

代替手段が、ある具体的な実務上の意味で劣るからです。

DXAは体組成の基準となる方法で優れたデータを与えますが、装置と技師、たいていは紹介が必要で、結果は装置によって変わります。水中体重法は水槽に沈むことを意味します。空気置換法にはBod Podが要ります。皮下脂肪厚計は安価ですが測る人の技術に大きく左右され、同じ人を二人が測れば数パーセントポイント違いうるのです。

BMIに必要なのは体重計だけです。それが唯一にして全部の論拠であり、公衆衛生の文脈では強い論拠です。

## 自分の数字をどう読むか

いくつかある入力のひとつとして扱ってください。しかも読み込みすぎやすい入力として。

BMIが健康的な範囲にあり、腹部に目立つ重さもないなら、すでに知っていること以上のことはほとんど教えていません。それでかまいません。範囲から大きく外れているなら、その理由を理解する価値があります。答えが筋肉であれば数字が誤解を招いているということですし、そうでない場合もあります。

より示唆に富む次の一歩は、ウエスト周囲径、またはウエスト身長比です。どちらもBMIには見えない腹部の脂肪をとらえます。US Navy法による[体脂肪率の推定](/ja/calculators/body-fat/)も、3〜4パーセントポイントの誤差を認めたうえでなら有用です。血圧や血液の指標は、体型ではなく健康そのものを測ります。

BMIがあなたに教えられないのは、あなたが健康かどうかです。そのために作られたものではなく、考案者もそう主張せず、名づけた本人が1972年に明言しています。
