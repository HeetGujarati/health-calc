体重80 kg、身長180 cm、30歳の男性を基礎代謝量の標準的な3つの式に通すと、1,780、1,854、そして除脂肪体重が64 kgと分かっていれば1,752になります。おおよそ100 kcalの幅で、これは上から活動係数を掛けた時点でさらに広がります。

3つとも正しいということはありえません。どれを使うか、その決め方を示します。

## 候補

**Mifflin-St Jeor**（1990年）は、間接熱量測定で測った健康な成人498人から得られました。

```
男性: BMR = 10×体重 + 6.25×身長 − 5×年齢 + 5
女性: BMR = 10×体重 + 6.25×身長 − 5×年齢 − 161
```

**改訂Harris-Benedict**（RozaとShizgal、1984年）は、より大きなデータセットで1919年の元の式を作り直したものです。

```
男性: BMR = 88.362 + 13.397×体重 + 4.799×身長 − 5.677×年齢
女性: BMR = 447.593 + 9.247×体重 + 3.098×身長 − 4.330×年齢
```

**Katch-McArdle**は変数をひとつしか使いません。

```
BMR = 370 + 21.6 × 除脂肪体重（kg）
```

体重はキログラム、身長はセンチメートル、年齢は歳です。

## 検証研究が見いだしたこと

最もよく引かれる比較は、American Dietetic AssociationのためにFrankenfieldらが行った系統的レビューです。各式が実測の安静時エネルギー消費量を10パーセント以内で予測できた頻度を評価しました。

Mifflin-St Jeorは肥満のある成人にもない成人にも最も良い成績を示し、Academy of Nutrition and Dieteticsが推奨する式でもあります。Harris-Benedictは改訂版を含めて高めに出る傾向があり、たいてい5パーセント前後、肥満のある人ではさらに大きくなりました。

理由は単純です。HarrisとBenedictは20世紀初頭に239人を測りました。そのコホートは現代の集団と体組成の点で、そしておそらく誰も記録しなかった点でも異なっていました。さらに熱量測定そのものが、二つの研究を隔てる70年のあいだに大きく進歩しています。改訂版の小数点以下の桁数は当てはめの産物であって、余分な正確さではありません。

## Katch-McArdleという例外

Katch-McArdleが面白いのは、3つのうち最良になるか最悪になるかが、たったひとつのことで決まるからです。

体組成に反応する唯一の式です。身長、体重、年齢、性別はどれも、代謝的に活発な組織をどれだけ持っているかの代理でしかありません。除脂肪体重はその量そのものです。それが分かっているなら、代理を飛び越えて、本当に効く変数に直接たどり着いたことになります。

だからこそ、体組成が平均から外れた集団——鍛えた競技者、体脂肪率の高い人、身長と体重の代理が読み違える人——では他の式を上回ります。細くて筋肉のある人に対して、Mifflin-St Jeorは筋肉が見えないぶん低めに出ますが、Katch-McArdleは見えます。

落とし穴は入力にあります。除脂肪体重を実測している人はほとんどいません。多くの人が持っているのは推定値で、たいていは巻き尺かBMIに基づく式からのものです。そしてそれらは3〜4パーセントポイントの誤差を抱え、その誤差はそのまま基礎代謝量の数字へ伝わります。

したがって順位は入れ替わります。

- **DXAで実測した除脂肪体重:** Katch-McArdleが3つのうち最も正確。
- **巻き尺から推定した除脂肪体重:** Mifflin-St Jeorとおおむね同等で、ばらつきはより大きい。
- **BMIから推定した除脂肪体重:** Mifflin-St Jeorより劣る。得るものなしに、2つ目の式の誤差を1つ目に足したことになるからです。

[基礎代謝量の計算ツール](/ja/calculators/bmr/)は、除脂肪体重が与えられていないときBoerの式で推定し、そのことをページに明記しています。誠実ではありますが、あくまで推定です。この注記は、Katch-McArdleの数字を実測値と取り違える人が出ないようにするためにあります。

## 実務上の答え

**Mifflin-St Jeorを使ってください。** ただし体脂肪率を実測している場合を除きます。一般の集団に対して最もよく検証された式であり、すでに知っている情報だけで足ります。

**Katch-McArdleを使ってください。** DXAを受けたか、信頼できる体組成の測定値がある場合、とくに際立って細い人や際立って筋肉質な人なら。代理変数に頼る式が最も苦戦するのがそこです。

**Harris-Benedictを使ってください。** 古い資料と突き合わせるとき、あるいは併用している別の仕組みがこの式を使っていて整合を取りたいときに。正確だからではありません。正確ではないからです。

## 勝者より「幅」のほうが重要な理由

持ち帰るべきことはこれです。式どうしの食い違いは、どの式ひとつをとってもその誤差より小さいのです。

予測式は多くの人で、実測の安静時消費量の10パーセント以内に収まります。1,800 kcalの10パーセントは180 kcalです。同じ人に対するMifflin-St JeorとHarris-Benedictの差はふつう70〜100 kcalで、どちらの誤差の範囲にも十分収まります。

つまり「正しい」式を選ぶことで得られるものは、感じられるほど大きくありません。あなたが選んでいるのは、ほぼ同じ不確かさを抱えた3つの推定であり、最もよく検証されたものを選ぶのは賢明ではあっても決定的ではないのです。

[計算ツールが3つとも表示する](/ja/calculators/bmr/)のは、まさにそのためです。3つが近くに固まっていれば、推定はおそらく妥当です。大きくばらついていれば——身長・体重・年齢の両極でそうなります——そのばらつき自体が、単一の数字が示唆するほどには信用に値しないと告げています。

## その数字をどう扱うか

食べる量にしないでください。基礎代謝量は一日中動かずに横たわっていた場合に必要な量であり、カロリー目標への入力であって目標そのものではありません。この区別は[基礎代謝量はどう計算されるのか](/ja/guides/how-bmr-is-calculated/)で扱っており、ここを取り違えることがこれらの式に関する最も影響の大きい誤読です。

活動レベルを掛けて総エネルギー消費量を求めてください。そのとき、係数のほうが式の選択よりも大きな誤差を持ち込むことは受け入れてください。そのうえで結果を出発点の仮説として扱い、二週間その水準で食べ、体重が実際にどう動いたかから調整します。

自分自身の測定された反応は、このページのどの式よりも優れています。そしてそれを得るのに必要なのは二週間です。
