基礎代謝量とは、体が何もしていないときに使うエネルギーです。ソファでくつろぐことではなく、文字どおり何もしないこと。目は覚めたまま動かずに横たわり、温度が中立な部屋にいて、12時間何も食べていない状態です。生きていること自体の費用、つまり脳を動かし、心臓を打たせ、体温を保ち、細胞を入れ替えるための費用です。

多くの人にとって、これが一日のエネルギー消費の大半を占めます。起き上がろうが起き上がるまいが、一日に燃やす量の60〜75パーセントほどはここで生じます。だからカロリーの計算はどれもここから始まります。

## 実際に測っているもの

基準となる方法は間接熱量測定です。フードの下に横たわるかマスクで呼吸をし、装置が酸素の消費量と二酸化炭素の産生量を測ります。脂肪と糖質の酸化は既知の比率で酸素を消費するので、ガス交換から数パーセントの誤差でエネルギー消費量が分かります。誰かが熱を直接測る必要はありません。

うまく機能する方法ですが、利用できる人はほとんどいません。代謝測定装置は数万ポンド規模で、検査は管理された条件下で30分かかり、絶食して休んだ状態で来る必要があります。そこで現実的な代わりが予測式です。大きな集団をきちんと測り、ばらつきの大半を説明する変数を見つけ、式を当てはめる。

[基礎代謝量の計算ツール](/ja/calculators/bmr/)にある3つの式は、まさにそれです。実測データへの回帰であって、生理の記述ではありません。

## なぜ身長・体重・年齢・性別なのか

この4つの変数は恣意的ではありません。それぞれが代謝上の実体の代役を務めています。

**体重**は圧倒的に強い予測因子です。どれだけ組織を持っているかの代理になるからです。組織が多いほど維持に費用がかかります。ただし不完全でもあります。脂肪組織は臓器や筋肉に比べて代謝活性がはるかに低いため、体重が同じでも体組成が違う二人は本当に違い、体重の項ではそれが見えません。

**身長**は体重だけでは逃してしまう情報を加えます。体重が同じなら、背の高い人のほうが体表面積が広く、熱を速く失い、組織の分布も異なります。体表面積は19世紀の代謝予測の元々の土台でした。体重ベースの式がそれに取って代わる前のことです。

**年齢**は実在する低下を捉えます。代謝率は成人期を通じて下がります。一部は除脂肪量の減少により、一部は残った組織の代謝活性の低下によります。式はこれを直線として扱っており、それは単純化ですが、向きとおおよその大きさはよく確かめられています。

**性別**が出てくるのは、身長・体重・年齢が同じなら、男性のほうが平均して除脂肪量が多く脂肪が少ないからです。係数はその平均的な体組成の差の代役にすぎません。個人についての主張ではありません。同じ体格の筋肉質な女性と平均的な男性では代謝がほぼ同じになりうるのに、式にはそれが判別できません。

何が欠けているかにも注目してください。あなたの実際の体組成、甲状腺の機能、遺伝、最近の減量歴——どれも実際の代謝率を動かしますが、どれも入力にはなっていません。

## 3つの式

**Mifflin-St Jeor**（1990年）は、ここでも多くの臨床現場でも既定の式です。

```
男性: BMR = 10×体重 + 6.25×身長 − 5×年齢 + 5
女性: BMR = 10×体重 + 6.25×身長 − 5×年齢 − 161
```

体重はキログラム、身長はセンチメートル、年齢は歳です。Mifflinらは健康な成人498人を間接熱量測定で測り、そのデータに式を当てはめました。

**改訂Harris-Benedict**（RozaとShizgal、1984年）は、1919年の元の式を作り直したものです。

```
男性: BMR = 88.362 + 13.397×体重 + 4.799×身長 − 5.677×年齢
女性: BMR = 447.593 + 9.247×体重 + 3.098×身長 − 4.330×年齢
```

小数点以下が多いだけで、精度が高いわけではありません。その細かさは当てはめの副産物であって、予測の良さを主張するものではありません。

**Katch-McArdle**はまったく別の道をとります。

```
BMR = 370 + 21.6 × 除脂肪体重（kg）
```

変数はひとつ。性別の係数はありません。性別の項が代役を務めていた差を、除脂肪体重がすでに含んでいるからです。

## なぜ食い違うのか

同じ人を3つの式に通すと、ふつう100〜300 kcalの幅が出ます。体重80 kg、身長180 cm、30歳の男性なら、Mifflin-St Jeorは1,780、改訂Harris-Benedictは1,854です。差は74 kcalで、範囲の両端ではさらに広がります。

理由は3つあります。

**集団が違う。** HarrisとBenedictは20世紀初頭に239人を測りました。その人たちは現代の集団と、体組成でも活動量でも、そしておそらく誰も記録しなかった点でも違っていました。Mifflin-St Jeorは1980年代末に測られた人々に当てはめられています。どちらのコホートも間違ってはおらず、ただ違うだけで、係数はそれを映しています。

**方法が違う。** 熱量測定は1919年から1990年のあいだに大きく進歩しました。式のあいだの差の一部は、生物学ではなく測定技術です。

**変数が違う。** Katch-McArdleは除脂肪体重だけを使います。除脂肪体重が実測されているなら、それが3つのうち最も正確な理由になります。体組成に反応する唯一の式だからです。除脂肪体重を別の式で推定した場合は、その式の誤差を引き継ぎ、いちばん不正確になります。だから計算ツールは、推定値を使っているときはっきりそう述べます。

改訂Harris-Benedictは高めに出る傾向があり、たいてい5パーセントほどです。Academy of Nutrition and Dieteticsが、肥満のある成人にもない成人にもMifflin-St Jeorを推奨しているのはそのためです。

## これらはどれほど正確なのか

予測式は多くの人で、実測の安静時エネルギー消費量のおよそ10パーセント以内に収まります。厳しそうに聞こえますが、換算してみてください。1,800 kcalの10パーセントは一日180 kcalで、ひと月ではおよそ体重0.75キログラム分のエネルギーに相当します。

個人の誤差はもっと大きくなりえます。実測値がどの式の予測からも15〜20パーセント離れている少数の人が、研究では一貫して見つかります。そして、その人が誰なのかを事前に見分けられる式はありません。

実務上の含意は、この数字が無用だということではありません。目標ではなく出発点だということです。基礎代謝量と活動量の推定が示す水準で2〜3週間食べ、体重に実際に何が起きるかを記録し、観察された結果から調整してください。あなた自身の反応は、他人に当てはめられたどの回帰よりも良いデータです。

## 基礎代謝量ではないもの

これは「食べるべき量」ではありません。これが最も多く、最も影響の大きい読み違えです。基礎代謝量は、暗い部屋で一日中動かず横たわっていた場合に必要な量です。ふつうの生活を送りながらその水準で食べれば、かなりの不足になります。たいていは意図よりずっと大きく、しばしばこのサイトが設ける下限も下回ります。

摂取量のために必要な数字は総エネルギー消費量で、基礎代謝量に活動係数を掛けたものです。それは[TDEEの活動係数が実際に意味するもの](/ja/guides/what-activity-multipliers-mean/)で扱っており、カロリー目標に残る不確かさの大半はそこにあります。

## 減量すると基礎代謝量は下がるのか

下がります。分けて考えるべき理由が2つあります。

ひとつは算数であり、まったく想定どおりです。小さい体は動かすのに費用がかかりません。ここにあるどの式も体重の項でそれを表しています。10 kg減ればMifflin-St Jeorは基礎代謝量を100 kcal下げます。あなたの量が減ったからです。

もうひとつはより興味深い話です。適応的熱産生、つまり組織の減少だけから予測される以上に代謝率が下がる現象には、相応の証拠があります。その大きさと持続については本当に議論があり、推定は「無視できる」から数百キロカロリーまで幅があります。大きな効果を見いだす研究は、たいてい大幅で急速な減量を伴います。

いずれにせよ実務上の帰結は同じです。最初は着実な減量を生んでいた不足量が、同じ摂取量でも後になるほど減り方を小さくします。これは想定どおりであって失敗ではなく、[カロリー計算ツール](/ja/calculators/calorie/)がひとつの数字を恒久的なものとして扱わず、定期的に計算し直すよう勧めている理由のひとつでもあります。
