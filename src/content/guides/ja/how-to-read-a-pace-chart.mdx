ペース表は、ペースを距離ごとのゴールタイムに対応づけたものです。1キロメートルあたりのペースまで下り、距離まで横に読めば、そこにタイムがあります。

計算そのものは他愛ありません。面白いのは、ペース表に言えないことのほうです。そしてその隙間こそ、多くの人が使い方を誤るところです。

## 三つの量

ペース、速度、タイムは、同じ情報を三通りに言い換えたものです。

**ペース**は距離あたりの時間で、1キロメートル5:00のように表します。小さいほど速いので、比べるときに混乱のもとになります。

**速度**は時間あたりの距離で、時速12 kmのように表します。大きいほど速い。

**ゴールタイム**はペースに距離を掛けたものです。

換算はこうです。

```
1kmあたりのペース = タイム / 距離（km）
速度（km/h）      = 60 / 1kmあたりのペース（分）
ゴールタイム      = 1kmあたりのペース × 距離（km）
```

5:00/kmのペースは時速12 kmで、5 kmなら25:00、10 kmなら50:00、マラソンなら3:30:59になります。

走る人はペースで考えます。時計に出るのがペースであり、レース中に守るのもペースだからです。自転車に乗る人は速度で考えます。どちらが正しいということはありません。

## キロメートルとマイル

1マイルは1.609344キロメートルなので、1マイルあたりのペースは1キロメートルあたりのペースに1.609344を掛けたものです。

5:00/kmは8:03/マイル。4:00/kmは6:26/マイル。6:00/kmは9:39/マイルです。

よく使われる「6割足す」という近似は暗算には十分ですが、マラソン全体では数秒ずれます。

## ラップと、最後の195メートル

ラップ表は、各区間での経過時間を示します。ペースが一定なら単純な掛け算であり、その価値はレース当日の目安として使えることにあります。15 kmを1:15:00で通過する予定なのに時計が1:13:30を指しているなら、飛ばしすぎです。

多くの表が取りこぼす細部がひとつあります。マラソンは42.195 kmなので、1キロメートルの区間を42本とったあと195メートルが残ります。42 kmで終わる表は、その最後の195メートルを黙って落としています。マラソンのペースではおよそ1分にあたり、しかも人が最も気にする1分です。

[ペースの計算ツール](/ja/calculators/running-pace/)はその最後の部分区間を表示し、部分区間であると明示します。ゴール線の手前で終わるラップ表は、いちばん大事なところで間違っているからです。

同じことは21.0975 kmのハーフマラソンにも、区間の長さで割り切れないあらゆるレースにも当てはまります。

## 他距離換算が外れる理由

「同等タイム」の表について理解しておくべきことがこれです。

5 kmを25:00で走れば、それは5:00/kmです。5:00/kmをマラソンで維持すれば、3:30:59でゴールする計算になります。

そうはなりません。誰もそうはなりません。

距離が伸びればペースは落ちます。理由は気持ちの問題ではなく生理です。グリコーゲンが減ります。体温調節が制限要因になります。筋の損傷が積み重なります。維持できる相対的な強度は時間が延びるほど下がり、よく鍛えたランナーでも10 kmなら閾値ペースの95パーセント、マラソンなら85パーセントといったところです。

ペース計算ツールの換算は一定ペースを前提にしており、ページにもそう書いてあります。答えているのは「同じペースなら別の距離でどうなるか」であって、条件をそろえた比較としては有用です。練習の設定には役立ちます。しかし「レースで何が出せるか」には答えていません。

## Riegelの式

実際の予測に使う標準的な道具は、Peter Riegelの式です。

```
T₂ = T₁ × (D₂ / D₁)^1.06
```

T₁は距離D₁での既知のタイム、T₂は距離D₂での予測タイムです。指数の1.06は疲労を表す係数で、ペースが完全に保たれるなら指数は1.0になります。超過分の0.06が、距離が伸びるにつれてどれだけ落ちるかを表しています。

先ほどの5 km 25:00に当てはめると、Riegelはマラソンを3:31ではなくおよそ3:57と予測します。一定ペースの換算より26分遅く、現実にずっと近い値です。

Riegelにも知っておくべき限界があります。目標距離にふさわしい練習を積んでいることを前提にしており、これは小さくない前提です。5 km専門で15 kmより長く走ったことがない人は、5 kmがどれほど速くてもRiegelのマラソン予測には届きません。指数も個人によって変わり、持久力をよく鍛えた人ほど実効的な指数が低く、距離が伸びてもペースをよく保ちます。そして5 kmからマラソンのように遠くまで外挿するほど、10 kmからハーフのような短い跳躍よりも誤差が積み重なります。

## イーブンペースとネガティブスプリット

生理学的には、たいていのレース距離でタイムトライアルの成績はイーブンペースが最適に近くなります。速く入ると乳酸が上がりグリコーゲンが早く減り、後半で失う時間が前半で得た時間を上回ります。

ネガティブスプリット——後半を前半より速く——という助言は、実のところ前半を突っ込むなという助言です。市民レースの多くは最初の3キロメートルで失われます。アドレナリンと、速い人たちに引っ張られることによってです。

ここでラップ表が役に立ちます。しかも具体的な使い方があります。目標ラップを手の甲か時計の文字盤に書いておき、序盤の数キロでは目標より*速い*ことを、気分の良い材料ではなく問題として扱うのです。

## 練習でのペース表の使い方

**閾値の練習**は10 kmからハーフマラソンのレースペース前後で、多くのランナーでは5 kmのペースよりおよそ1キロメートルあたり15〜20秒遅い水準です。

**イージーラン**は、多くの人が実際に走っているよりずっと遅くすべきです。ふつうは閾値より1キロメートルあたり60〜90秒遅くなります。イージーのペースと閾値のペースが近いなら、それは[心拍ゾーン](/ja/guides/understanding-heart-rate-zones/)で説明したグレーゾーンであり、多くの練習の労力が無駄になる場所です。

**レースペースの練習**が最も重要なのはマラソンです。特定のペースを何時間も保つこと自体がひとつの技術だからです。数字が体に馴染むまでラップ表を読み込むことは、準備の本当の一部です。
