TDEEの計算ツールはどれも同じ手順です。基礎代謝量を推定し、自己申告の活動量に応じて1.2から1.9のあいだの数を掛ける。この係数はたいてい確立した科学として提示され、Harris-BenedictやMifflin-St Jeorが出典として添えられます。

それらの論文に、これらの数字は載っていません。

これははっきり言っておく価値があります。出力にどれだけの信頼を置くべきかが変わるからです。活動係数はカロリー推定における最大の誤差要因であり、同時に公表された裏づけが最も弱い部分でもあります。

## 数字の出どころ

1.2が座位中心、1.375がやや活動的、1.55が中程度に活動的、1.725が非常に活動的、1.9が極めて活動的というこの並びは、1990年代以降にフィットネス文献と計算ツールのコードを通じて広まりました。慣習です。ある計算ツールの出典を十分にさかのぼると、たいてい別の計算ツールに行き着きます。

その下にある概念は実在し、よく研究されています。身体活動レベル、略してPALと呼ばれ、総エネルギー消費量を基礎代謝量で割った比です。一日2,400 kcal消費し、基礎代謝量が1,600ならPALは1.5です。研究者はこれを二重標識水法できちんと測ります。一〜二週間かけて体内から二つの同位体が消えていく様子を追い、日常生活下の総消費量を数パーセントの誤差で求める方法です。

つまりPALは測定可能であり、実際に何千人もで測られてきました。存在しないのは、「週に3〜5日の運動」がちょうど1.55に対応すると示した論文のほうです。

## 公表された枠組みが実際に述べていること

権威ある二つの出典がPALの区分を定めています。どちらも慣習的な5段階とはぴったり一致しません。

**米国医学研究所**は2005年の食事摂取基準で、二重標識水法のデータから四つの区分を定めています。

| 区分         | PAL       |
| ------------ | --------- |
| 座位中心     | 1.0〜1.39 |
| 低活動       | 1.4〜1.59 |
| 活動的       | 1.6〜1.89 |
| 非常に活動的 | 1.9〜2.5  |

**FAO/WHO/UNU**の専門家協議は、2004年のヒトのエネルギー必要量に関する報告で、三つの生活様式の区分を用いています。

| 生活様式               | PAL        |
| ---------------------- | ---------- |
| 座位中心または軽い活動 | 1.40〜1.69 |
| 中程度に活動的         | 1.70〜1.99 |
| 活発に活動的           | 2.00〜2.40 |

これらを慣習的な係数と並べると、目につくことがあります。慣習的な「座位中心」の1.2は、1.0から始まるIOMの座位中心の区分には収まりますが、FAOの下限1.40はまるごと下回ります。FAOの見方では、本当に座位中心の成人でもなお1.40前後になるのです。

どちらの枠組みも正当で、区分の定義が違い、依拠した集団も違います。ただしこの食い違いは有益なことを教えてくれます。慣習的な段階のうち、下端がいちばん当てにならない部分だということです。

[TDEE計算ツール](/ja/calculators/tdee/)は、各係数がどのIOM区分に入るかを併記しています。選んだ数字が、誰かの書いたラベルではなく実測データに対してどこに位置するのかが見えるようにするためです。

## 問題はラベルにある

「中程度に活動的——週に3〜5日運動」は精密に聞こえます。そうではありません。いちばん個人差の大きいものが抜け落ちているからです。

計画的な運動は、たいていの人の一日の消費量のうち意外なほど小さな部分です。中程度の運動を1時間行っても、上乗せは400 kcal程度でしょう。一方、机に向かって座り移動はすべて車という人と、一日中立ち仕事で通勤も徒歩という人の差は、運動をまったく含まずに700 kcal以上になりえます。

その成分には名前があります。非運動性活動熱産生、NEATです。歩くこと、そわそわすること、立っていること、姿勢など、運動ではないあらゆる動きを含みます。個人差は非常に大きく、過剰摂取の研究では、多く食べたときに人がどれだけ自然にNEATを増やすかに一日あたり数百キロカロリーの差があると報告されています。

したがって、同じ「週に3〜5日運動」を選んだ二人でも、一方が郵便配達で他方が在宅勤務なら、総消費量は本当に違います。係数はその差を見られず、ラベルはそれを尋ねません。

## それを踏まえてどう選ぶか

実用的な提案を三つ。

**最良の週ではなく、典型的な週で選ぶ。** 人は「こうありたい」と思う週に合う段階を選びがちです。トレーニングしなかった週も含め、直近の1か月を正直に表す段階を選んでください。

**迷ったら一段下げる。** 多くの人は活動量を過大に見積もり、その誤差は積み上がります。基礎代謝量1,700 kcalに対して係数が一段高いと、目標はおよそ300 kcal多くなります。やや低めから始めて体重が動かないときに上げるほうが、逆よりも立て直しやすいのです。

**そもそも使わない選択も考える。** 体重が1か月以上安定しているなら、あなたの維持摂取量はいま食べている量そのものです。それはあなたの実際の生活における実際のTDEEを、実際のNEATごと直接測った値です。どんな式にも勝ります。計算ツールが最も役立つのは、その基準がないとき——始めたばかりのときや、大きく変化した期間のあとです。

## 運動を二重に数えない

これは最も多い実務上の誤りで、うっかりやってしまいます。

週4回トレーニングするからと「中程度に活動的」を選んだなら、係数はすでにそのトレーニングを含んでいます。その上に[消費カロリー計算ツール](/ja/calculators/calories-burned/)の数字を足すと同じ運動を二度数えることになり、目標が数百キロカロリー膨らみます。

どちらか一方を選んでください。

- トレーニングを含む活動レベルを選び、運動ぶんのカロリーは上乗せしない。単純で、たいていの人にはこちらが適します。
- あるいは「座位中心」を選んで運動抜きの基準を定め、各セッションのエネルギーを個別に足す。不定期に運動するなら正確ですが、記録の手間はかなり増えます。

両者を混ぜることが、寛容そうに見えて機能しない目標を生みます。

## この数字は何のためにあるのか

TDEEの推定は仮説であって測定ではありません。他人に当てはめられた式に照らせば、あなたの体格と申告した活動量をもつ人はおおよそこれくらい消費するだろう、という意味です。

試してください。2〜3週間その水準で食べます。[体重が日によって変動するのはなぜか](/ja/guides/why-scale-weight-fluctuates/)で扱ったとおり、水分による増減が平均化されるだけの長さです。そして何が起きるかを見ます。体重が安定していれば推定は妥当でした。動くなら100〜200 kcal調整し、さらに二週間待ちます。

その一巡を終えれば、どんな計算ツールにも出せないものが手に入ります。当たっていなければならない唯一の人物で実測した、維持量の数字です。
